# Trabajo-Recuperatorio-de-laboratorio-de-programacion

# Ficha de Transparencia de IA

## 1. Herramienta
Utilicé ChatGPT para obtener ayuda durante el desarrollo del proyecto. También consulté recomendaciones de páginas para editar imágenes y quitarles el fondo.

## 2. Objetivo
Utilicé la IA para crear imágenes, buscar ideas para solucionar errores y encontrar herramientas que me ayudaran a editar los recursos gráficos del juego.

## 3. Prompt Exacto
Realicé diferentes consultas según los problemas que fueron apareciendo. Le pedí ayuda para crear y editar imágenes, recomendaciones de páginas para quitar fondos y sugerencias para solucionar errores del código.

No utilicé un único prompt para todo el trabajo, sino varias consultas diferentes.

## 4. Fundamentación
La IA me sirvió como asistente para buscar soluciones y probar alternativas, pero no pude implementar todos los cambios que tenía planeados.

Para modificar los sprites de los personajes, lo único que pude hacer sin que aparecieran errores fue cambiar muy poco la saturación de las imágenes.

Con el fondo también tuve dificultades, porque me resultó complicado conseguir que todos los NPC utilizaran la misma imagen. Por eso, solamente cambié uno y se nota la diferencia entre los frames.

Me quedaron pendientes modificar mejor el diseño de los personajes y sus ataques, cambiar el HUD para que la patada pesada figure con la tecla C en vez de la G, modificar el daño y la velocidad del Hadouken e implementar una nueva mecánica en JavaScript.

## 5. Aprendizaje
Aprendí que modificar las imágenes de un juego puede generar errores si no se tienen en cuenta sus formatos y dimensiones. También comprendí que para cambiar las mecánicas es necesario entender y modificar el código correspondiente.

Esta experiencia me permitió reconocer las dificultades que tuve y entender qué aspectos necesito seguir practicando, especialmente la edición de sprites y la programación en JavaScript.

## 6. Verificación
Los cambios que pude realizar fueron:

- Cambiar el sonido de fondo.
- Cambiar el sonido del Hadouken.
- Modificar ligeramente el aspecto de los personajes.
- Cambiar el fondo del juego.
- Cambiar el mensaje de victoria.
- Reemplazar el logo del juego.

Probé los cambios que pude integrar. Sin embargo, no logré completar todas las modificaciones previstas, por lo que algunos objetivos quedaron pendientes.

---

**Declaración:** Utilicé la inteligencia artificial como herramienta de apoyo para generar imágenes, buscar ideas y resolver dificultades. Los resultados finales corresponden a los cambios que pude realizar e integrar en el proyecto.
